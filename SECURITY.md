# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately, not through public GitHub issues.

Use [GitHub Security Advisories](https://github.com/rubicon/claude-session-exporter/security/advisories/new) for this repository to report a vulnerability. This gives us a private channel to discuss, fix, and coordinate disclosure before details become public.

We aim to acknowledge reports within a few business days and to keep you updated as we investigate and resolve the issue.

## Supported Versions

This project is pre-1.0 and in active development. Security fixes are made against the latest released version; there is no long-term support for older releases at this stage.
