# Support

## Getting Help

- **Bug reports and feature requests**: open a [GitHub issue](https://github.com/rubicon/claude-session-exporter/issues).
- **Usage questions**: open a GitHub issue with the `question` label, or start a [GitHub Discussion](https://github.com/rubicon/claude-session-exporter/discussions) if enabled.
- **Security vulnerabilities**: see [SECURITY.md](SECURITY.md) — do not open a public issue.

## Before Filing an Issue

- Check existing issues to avoid duplicates.
- Include your Python version, OS, and the exact command you ran.
- Include the full error output when reporting a bug.

There is no guaranteed response time; this is a solo-maintained open source project.
